# Screenshot Capture Checklist

Store screenshots must show the current release package running in a stable
browser. Do not substitute generated UI mockups.

The current 1280×800 PNG set contains:

1. `01-ratio-badges.png`: public synthwave search results with exact and
   approximate ratio badges.
2. `02-filter-sort-panel.png`: the open panel on Monstercat's public tracks page,
   populated with 1,000 minimum plays, 100 minimum likes, hidden unknown counts,
   and like-ratio ordering.
3. `03-sorted-filtered-results.png`: the resulting visible tracks ordered by
   like ratio, highest first.

Recapture the complete set when the extension interface or relevant SoundCloud
markup changes. Keep each image full-bleed with square corners and use the same
settings and public pages where practical.

Use a public SoundCloud page rather than the maintainer's library. Before
committing or uploading, inspect every image for account names, avatars,
notifications, private tracks, email addresses, browser-profile details, and
unrelated tabs. Crop or redact nonessential personal information without
altering the extension interface.

Screenshots should be current, crisp, and consistent with the submitted package.
