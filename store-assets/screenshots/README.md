# Screenshot Capture Checklist

Store screenshots must show the real `v1.0.0` package running in a current
stable browser. Do not substitute generated UI mockups.

Capture three 1280×800 PNG or JPEG images:

1. `01-ratio-badges.png`: several visible tracks with exact and approximate
   ratio badges.
2. `02-filter-sort-panel.png`: the open, populated Filter & sort panel.
3. `03-sorted-filtered-results.png`: results after applying a threshold and
   sorting by like ratio.

Use a public SoundCloud page rather than the maintainer's library. Before
committing or uploading, inspect every image for account names, avatars,
notifications, private tracks, email addresses, browser-profile details, and
unrelated tabs. Crop or redact nonessential personal information without
altering the extension interface.

Screenshots should be current, crisp, and consistent with the submitted package.
