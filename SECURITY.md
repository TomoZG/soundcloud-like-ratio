# Security Policy

## Supported versions

Only the latest published extension version receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a vulnerability or include user data, tokens, or
private account information in a report. Use GitHub's private vulnerability
reporting at:

https://github.com/TomoZG/soundcloud-like-ratio/security/advisories/new

Include the affected version, browser, reproduction steps, impact, and any
suggested mitigation. Reports are handled on a best-effort basis with no fixed
response SLA. Please allow reasonable time for investigation before public
disclosure.
