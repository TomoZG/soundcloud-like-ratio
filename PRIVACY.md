# Privacy Policy

Effective: August 1, 2026

SoundCloud Like Ratio is designed to work entirely in the user's browser.

## Information the extension accesses

On `soundcloud.com`, the extension reads website content needed for its single
purpose: visible track like counts, play counts, and the surrounding page
structure used to display, filter, and sort those tracks.

## How information is used

The information is processed locally in the current browser tab to calculate
like percentages and apply the controls requested by the user. The extension's
settings are held only in memory and reset when the page or tab reloads.

## Collection, transmission, and retention

The extension does not:

- transmit website content or browsing activity to the developer or a third
  party;
- use analytics, telemetry, advertising, tracking, or remote code;
- create user accounts or collect identifying, authentication, financial, or
  location information;
- persist track metrics, browsing history, or filter settings; or
- sell, share, or allow human access to information processed by the extension.

SoundCloud itself continues to operate the website and its network requests
under SoundCloud's own terms and privacy policy. This extension does not add
requests to SoundCloud or any other service.

## Limited use

The extension's access to website content is limited to providing its clearly
described like-ratio, filtering, and sorting features. Its use of information
complies with the Chrome Web Store User Data Policy, including the Limited Use
requirements.

## Support interactions

Information voluntarily included in a GitHub issue, pull request, or security
report is handled by GitHub rather than collected by the extension. Do not post
personal or sensitive information in a public issue.

## Changes and contact

Material privacy changes will be documented in this file, the store listings,
and the extension version as required. For a non-sensitive privacy question,
open a GitHub issue. Report sensitive security matters through GitHub's private
vulnerability reporting for this repository.
